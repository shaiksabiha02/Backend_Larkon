# Larkon Backend

## Project Overview

Larkon Backend is a RESTful API built using Node.js and Express.js. It provides backend services for the Larkon application, including authentication, user management, and other business modules.

## Tech Stack

- Node.js
- Express.js
- MySQL
- Postman (API Testing)
- Git & GitHub

## Team Workflow

- `main` → Stable production-ready code
- `develop` → Integration branch
- Individual developer branches → Feature development

## Getting Started

### 1. Clone the repository

```bash
git clone <https://github.com/shaiksabiha02/Backend_Larkon>
```

### 2. Install dependencies

```bash
npm install
```

### 3. Start the server

```bash
npm start
```
